# duylongpro99/tap

Homebrew formulae for [wib](https://github.com/duylongpro99/wuts-that-bash), shell history suggestions under your zsh prompt.

```sh
brew install duylongpro99/tap/wib
```

Upgrade with `brew upgrade wib`, then open a new terminal.

`Formula/wib.rb` is generated by the wib release workflow; changes made here are overwritten on the next release.
